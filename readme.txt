A professional multi-step custom QR code generator with decorative frames, module styles, logo overlays, gradient colors, and live device preview.

== Description ==

QR Code Generator Pro brings a premium, multi-step interactive QR code builder to your WordPress website.

= Features =
* 3-Step Guided Wizard (Type -> Content -> Design)
* Core QR Types: Website URL, Plain Text, WiFi, vCard, Email, Phone, SMS, WhatsApp, Location, Event.
* Decorative Frames: "SCAN ME" Banners, Badges, Smartphone borders, Coffee Cups, and more.
* Custom Module Dot Patterns & Corner Shapes.
* Solid & Gradient Colors, Background Transparency & Invert mode.
* High-res PNG & SVG Vector Downloads.
* Responsive live preview with Smartphone Mockup view.
* Simple shortcode: `[custom_qr_generator]`

== Installation ==

1. Upload the `qr-code-generator-pro` folder to the `/wp-content/plugins/` directory or upload the `.zip` file via WP Admin -> Plugins -> Add New.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Place `[custom_qr_generator]` shortcode on any page or post.
